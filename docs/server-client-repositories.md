# 仓库拆分与升级职责

产品服务端使用 `-server` 仓库；已有独立安装客户端使用 `-client` 仓库。管理 Web 随被管理的一端。
`sarmg-upgrade` 仍是独立离线工具，不拆成空 Server/Client，也不成为在线客户端更新程序。

仓库改名不改变本工具的产品 ID、代码允许的版本、Schema 指纹或状态边界。
Sunshine Server 的新 Schema 6、Host Server 的新 Schema 4、Media Server 0.3.0，以及新 Client 的
本地身份、队列和执行日志，均不能因仓库拆分或 CI 通过而视为本工具已支持。
本轮没有增加迁移、旧名称兼容、自动下载安装或新状态恢复能力。

既有测试夹具和历史源码快照保留其原始字段及身份，用于验证明确的版本拒绝边界；不机械改写为新客户端字段。
