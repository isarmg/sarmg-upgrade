# 产品与工具的归属

六个服务端提供自身当前结构、资源范围、发行身份和部署诊断。管理网页随对应服务端交付；独立客户端的本地队列、执行记录和凭据不由本工具升级。

`xssc` 是唯一服务端版本升级入口。所有升级规范、流程、支持范围与验收记录集中在本仓库；产品本身只提供当前状态和维护/诊断接口，不维护平行下载、切换或恢复流程。

本工具的产品目录只列出六个被维护的运行服务，实际资源从产品 `state_paths` 与签名定义获得。数据库标签可稳定于软件版之前，不能据此判断历史软件发行。当前到未来同合同机制与完整恢复见[离线升级](offline-upgrades.md)。

当前不维护预基线 SQL 夹具或产品历史解析器；真实产品演练由当前 init建库，验证完整业务行、媒体和实际程序就绪。发布资产和源码身份在[验证台账](validation.md)集中记录。
