# Server、Client 与离线工具的职责

产品服务端使用 `-server` 仓库，独立安装客户端使用 `-client` 仓库；管理 Web 随被管理的一端交付。
`sarmg-upgrade` 是独立离线工具，负责支持矩阵中明确实现的备份、验证与恢复操作。

产品仓库名称和最新发行版本不会自动改变本工具的产品 ID、允许版本、Schema 指纹或资源边界。
执行前以 `support --json` 核对精确持久化状态版本；当前适配器覆盖五个 Server 的已核验状态，不包含独立 Client 的本地队列与执行日志，
也不提供自动下载安装、在线更新或跨版本转换。产品二进制版本与其数据库中记录的状态版本可以不同。

仓库内的[当前 Schema 快照](../tests/fixtures/current)固定五个 Server 的实际 DDL；
测试重新计算 Schema 指纹，并验证备份、恢复与密文认证边界。
