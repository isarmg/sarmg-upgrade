# Server、Client 与离线工具的职责

产品服务端使用 `-server` 仓库，独立安装客户端使用 `-client` 仓库；管理 Web 随被管理的一端交付。
`sarmg-upgrade` 是独立离线工具，负责支持矩阵中明确实现的备份、验证与恢复操作。

产品仓库名称和最新发行版本不会自动改变本工具的产品 ID、允许版本、Schema 指纹或资源边界。
执行前以 `support --json` 核对精确版本；当前工具不支持最新 Server 状态或独立 Client 的本地队列与执行日志，
也不提供自动下载安装、在线更新或跨版本转换。

测试夹具和源码快照绑定各自的产品版本与原始状态身份，用于验证明确的接受和拒绝边界；
fixture 策略见[源码夹具说明](../tests/fixtures/sources/README.md)。
