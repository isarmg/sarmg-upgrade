# Dufs 0.51.0 支持边界

Dufs 0.51.0 的 Axum/Foundation 迁移没有给 sarmg-upgrade 增加新的当前状态适配。
本工具暂不支持该版本的备份、验证、恢复或升级；`support --json` 的 Dufs 精确版本仍为 0.50.1，不能外推到 0.50.2 或 0.51.0。

禁止修改旧数据库 metadata 绕过身份检查，禁止用空数据库搭配含上传暂存、未决操作或待清理对象的旧共享树，也不能将旧二进制直接指向新版本状态。迁移验收使用完整的新实例状态；真实旧实例保持原样，待独立离线处置方案获验后处理。

若将来支持 0.51.0，必须在本仓库更新精确 SchemaIdentity、组合资源合同和中断恢复测试，并重新发布；产品 HTTP 框架迁移不承担这些职责。
