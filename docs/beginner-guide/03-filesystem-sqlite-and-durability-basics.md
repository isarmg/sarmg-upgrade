# 3. 文件系统、SQLite 和持久性

路径字符串相同不能证明对象未被替换。工具拒绝非规范拼写、符号链接、特殊文件、多链接和组/其他用户可写对象，记录目录设备号/inode。完整部署唯一允许的符号链接是受控 `current`，目标为明确定义的物理版本发行根目录。

快照按目录项保存权限模式、字节、SHA-256，并另外记录每项 UID/GID。恢复使用不跟随链接的文件描述符和受控临时文件，验证后原子替换、fsync 文件和父目录。整组数据恢复需维护门和排他锁；不声称多个独立 rename 本身是一个跨文件事务。

SQLite 在 WAL 模式下，已提交数据可能仍在 WAL。产品 `state_paths` 报告数据库父目录，工具确认已停并取得维护权后复制主库和附属文件整组，避免遗漏。本工具不解释产品历史数据库；真实 DDL、完整性/FK 和业务约束由产品只读校验负责。

持久事务日志在有副作用操作前写入意图。`backup-complete` 只在全组清单/摘要验证后出现，部分目录绝不能被当作可恢复备份。运行权交接前写“可能已产生业务写入”，即使之后启动失败也保全新数据。

工具不复制 xattr/ACL、稀疏布局和硬链接关系。当前范围明确依赖安全权限和完整逻辑字节快照。
