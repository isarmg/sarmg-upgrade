# sarmg-upgrade 0.3.2

本版提供五个 Server 当前持久化状态的离线备份、校验和恢复。`support --json` 列出可执行操作；产品程序版本可以高于其数据库中记录的状态版本。

| Server | 持久化状态版本 | 资源 |
|---|---|---|
| Host Monitoring | `0.9.26` | SQLite |
| Sunshine Manager | `0.10.1` | SQLite、外部凭据密钥 |
| Media Backup | `0.3.0` | SQLite、数据树 |
| Sentinel Monitor | `0.2.2` | SQLite、录像树、三个配置文件、外部凭据密钥 |
| Dufs RAM | `0.51.0` | SQLite、共享目录、`dufs.yaml` |

Sunshine 和 Sentinel 会以 Foundation 当前密封格式认证持久密文。Dufs 备份核对数据库与共享目录的设备号和 inode；恢复时把暂存数据库绑定到新的共享目录，并在恢复日志中保留源摘要与目标摘要。组合恢复日志使用精确格式版本 4，缺失或未知字段会被拒绝。
使用 Foundation 平台库的 Server 必须带当前平台元数据；Sunshine 还会验证 Manager ID。

工具固定使用 Foundation Server `=0.9.1` 的不可变 Git revision。正式制品只支持 `x86_64-unknown-linux-gnu`，包含签名、校验和、SBOM、provenance 与支持矩阵快照。
发行签名公钥的 DER SHA-256 指纹为 `a12719e9a174ce673ef58cdaa04d606135c57f401c50b95246d3c1bebef33d68`。

当前没有跨版本数据转换命令，`upgrade_edges` 为空。后续 Server 若保持相同持久化状态身份，可以继续使用对应适配器；若 Schema、密文或资源边界变化，需在本仓库加入精确来源/目标适配器、转换测试与恢复证据后再发布新的工具版本。
