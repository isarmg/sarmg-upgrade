# sarmg-upgrade 0.3.4

- 读取当前状态文档和 SQLite 主库时复核普通文件身份及大小，拒绝特殊文件和读取过程中的文件替换。
- 正式发行签名前核对暂存 metadata 的版本、事件提交、二进制和能力目录摘要；身份不一致时停止发行。
- 五个 Server 的当前持久化状态备份、校验和恢复合同保持由 `support --json` 精确列出，`upgrade_edges` 仍为空。

工具固定 Foundation Server `=0.9.2` 的不可变 Git revision。正式制品只支持 `x86_64-unknown-linux-gnu`，包含签名、校验和、SBOM、provenance 与支持矩阵快照。
