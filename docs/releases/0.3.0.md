# sarmg-upgrade 0.3.0 候选说明

本候选版本对恢复日志使用统一的有界读写契约。写入方在创建日志或替换目标前完整序列化并校验内容；检查清单时只读取不超过 1 MiB 的普通文件，拒绝符号链接、目录和 FIFO。

两个 Foundation Server crate 固定为 `=0.9.1` 和同一完整 Git revision。工具使用共享线格式与 Schema 身份类型，不依赖相邻源码目录，也不提供 Web 包。

当前二进制仅声明其内置适配器实际验证过的状态身份：Host Monitoring `0.8.0`、Sunshine Manager `0.8.0`、Media Backup `0.2.0`、Sentinel Monitor `0.2.0` 和 Dufs RAM `0.50.1`。`support --json` 是支持范围的权威机器可读输出；这些版本不等于各产品最新发行版，也不提供跨版本转换。

**状态：尚未正式发布。** 当前产品数据库及数据树的 Schema 已与上述适配器不同。发布前必须更新并验证各产品适配器、真实备份与恢复流程，还必须在 GitHub Release 工作流中使用仓库固定公钥对应的 `RELEASE_SIGNING_KEY_PEM` 完成签名和复验。不得将依赖更新或单元测试通过解释为当前产品状态可恢复。
