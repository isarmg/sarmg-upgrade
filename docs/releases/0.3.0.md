# sarmg-upgrade 0.3.0

状态：候选版本，尚未正式发布。除签名密钥缺失外，Host、Sunshine、Media、Sentinel 的当前数据库 Schema 适配尚未跟上本轮产品改造；仅更新版本字符串和单元测试通过不能证明可验证、备份或恢复这些新产品状态。必须完成当前 Schema 适配与真实产品验收后才能发布，不增加旧 Schema 读取器或转换路径。

仅提供当前状态的验证、备份和恢复；锁定 Server Foundation 0.6.0。

Foundation 产品标识改为 sarmg-foundation-server，Host 当前状态身份同步到 0.8.0；不新增旧版本读取器、转换器或升级边。

本次是现有改造工作的阶段收尾，不代表《更新手册》全部完成。不保留旧代码、旧名称或旧版本合同的兼容路径；当前版本部署应使用本版本发行说明和状态合同。

Rust Foundation 依赖锁定完整 Git revision 与精确版本，不依赖同级源码目录；本工具没有 Web 发行包。发布以精确提交的 CI 和实际发行制品验收结果为准。

正式发行必须使用仓库已固定公钥对应的 RELEASE_SIGNING_KEY_PEM 签名并复验；缺失密钥时不能发布未签名的替代正式包。
