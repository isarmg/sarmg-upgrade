# sarmg-upgrade 0.3.0

仅提供当前状态的验证、备份和恢复；锁定 Server Foundation 0.6.0。

Foundation 产品标识改为 sarmg-foundation-server，Host 当前状态身份同步到 0.8.0；不新增旧版本读取器、转换器或升级边。

本次是现有改造工作的阶段收尾，不代表《更新手册》全部完成。不保留旧代码、旧名称或旧版本合同的兼容路径；当前版本部署应使用本版本发行说明和状态合同。

Rust Foundation 依赖锁定完整 Git revision 与精确版本；Web Foundation 依赖使用 v0.6.0 发行 tarball 与 lockfile 完整性值，不依赖同级源码目录。发布以精确提交的 CI 和实际发行制品验收结果为准。

正式发行必须使用仓库已固定公钥对应的 RELEASE_SIGNING_KEY_PEM 签名并复验；缺失密钥时不能发布未签名的替代正式包。
